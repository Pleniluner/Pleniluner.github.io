Pleniluner / 清月です。

Pleniluner、あるいは Elysia と呼んでもらっても構いません。

名前の由来

Pleniluner は Plenilune Annals（盈月紀年）に由来し、少し改まった場で使う名前です。記録に残る限り、日本で発売された最初の中国発の東方同人作品だったことから選びました。その背景にある歴史を大切にしています。

Elysia は Elysia's Heart に由来する、より親しみのある名前です。この曲は長年のお気に入りです。軽やかで澄んだ鮮やかさがあり、その感覚とともに、勇気を持って自分の足で歩んでいきたいと思っています。

システムや性能に関わる処理には C/C++、Android アプリには Kotlin、計算・画像・信号処理には Python と MATLAB を使っています。コンパイラ、プロセッサ設計、機械学習、コンピュータグラフィックスにも関心があります。

プログラムを命令のレベルまで追うこと、数学の問題をじっくり解くこと、雑音の多い録音から何かを聞き分けることが好きです。

建築を学ぶ学生で、コールサイン BG7LBJ のアマチュア無線家でもあります。星を眺め、ときには Minecraft で建築もします。コードと図面の間には、たいてい東方の音楽が流れています。

03 / 近況

いま作業机にあるもの

Android で天文現象を追う

Kotlin、Jetpack Compose、Android SDK を使い、天文現象を追跡するアプリを開発しています。

天文情報がひと目で役に立つ画面に関心があります。使い心地を支えるアニメーション、ジェスチャー、キャッシュ、性能にも取り組んでいます。

無線、信号、つながる機器

SDR、スペクトル解析、プロトコルのデコード、デジタル通信を探りながら、無線通信と深層学習を組み合わせた IoT プロジェクトにも取り組んでいます。

無線の実験は、標本化理論、フィルタ、変調、雑音解析を実際に確かめる場になっています。

画像、音声、科学データ

公開天文データを使い、画像の較正、スタッキング、後処理を試しています。

音声では、デジタルフィルタ、コーデック、モバイル音声処理、ルーム補正に関心があります。音声・映像・データのリアルタイム通信に向けて WebRTC も探っています。

アルゴリズムと数学の問題

ACM 形式の問題演習、データ構造の実装、グラフアルゴリズム、動的計画法、数論の問題に取り組んでいます。

娯楽数学や AMC の問題も、解くこと自体を楽しんでいます。

建築と、思い描く場所

新中式建築、中国の水墨画、現代の空間設計をめぐるアイデアを育てています。

スケッチや模型になるものもあれば、Minecraft の建物になるものもあります。

次に試してみたいこと

ほかにも、少しずつ手を動かしてみたいことがあります。

  • 個人サイト — プロジェクト、ノート、創作を置く場所に。新しい見た目や操作感を試せる余地も残したいです。
  • TArch + AI — 適した CAD MCP ツールを探し、天正建築 / TArch と連携できるか確かめたいです。AI に作図と数回の修正を試してもらい、最後は自分で図面を確認するつもりです。繰り返しの作図は、少し手伝ってもらえると助かります。
  • 授業の課題から小さなプロジェクトへ — 下に挙げた講義資料の課題や実験から逆算し、言語を使いこなすには何を理解し、何を独力で作れるべきか考えたいです。学びながらノートとコードをまとめていきます。
  • Pleniluner’s Workstation の Hackintosh — ASUS ROG Strix G16（2025、G614PR）— 銀月工作站 / Pleniluner’s Workstation に macOS Sequoia 15 の環境を整え、設定、互換性、問題を記録する予定です。新しい macOS は、ハードウェアの対応状況を確かめてから探りたいです。
  • UV-K5 に小さな幻想郷を — Quansheng UV-K5 用の既存の東方 Project テーマを探し、導入したり、使用中のファームウェア向けに調整したりしてみたいです。
  • 電鍵と Aura Sync — 無線の電鍵を ASUS 公式 Aura Sync につなぎ、机の照明が打鍵のリズムに合わせて動く仕組みを探りたいです。

形になってきたら、それぞれにリポジトリを用意し、コード、つまずいたこと、継続的な更新をまとめていくつもりです。

プログラミング言語

アセンブリ、ハードウェア、並列処理

x86 / x86-64 アセンブリ · MIPS アセンブリ · Verilog · VHDL · CUDA C++ · ISPC · POSIX スレッド · FPGA

システム分野では、メモリ管理、割り込み、プロセス、スケジューリング、同期、ファイルシステムのインターフェースを扱います。アセンブリとデバッガで、呼び出し規約、スタックフレーム、メモリ配置、実行ファイルの動作を調べます。

デジタル回路では、組合せ回路と順序回路、プロセッサのパイプライン、フォワーディング、ストール、例外、メモリマップド I/O を扱います。

並列プログラムでは、スレッド同期、ベクトル化、キャッシュの挙動、GPU メモリアクセス、速度向上を制限するオーバーヘッドを調べます。

コンパイラとソフトウェア構築

字句解析、構文解析、抽象構文木、記号表、型検査、中間表現、制御フロー解析、レジスタ割り当てを扱います。

コンパイラ用の道具には Flex / JFlex、YACC / BYACC/J があります。

C++ では、所有権、RAII、ムーブセマンティクス、テンプレート、STL を使います。明確なインターフェース、管理できる依存関係、再現可能なビルド、意味のある動作を確かめるテストを大切にしています。

アプリ、インターフェース、ネットワーク

Android SDK · Jetpack Compose · Qt / Qt Widgets · Java Swing Django · SQLite · Scrapy · Lucene · WebRTC

状態の永続化、バックグラウンド処理、ネットワーク通信を備えたイベント駆動型のアプリを作ります。

Android のライフサイクル、Qt のシグナルとスロット、データベースアクセス、応答性のある画面を扱います。ソケットでは、メッセージの区切り、部分読み取り、タイムアウト、同時接続を考慮します。

ネットワークでは TCP/IP、ルーティング、輻輳、DNS、HTTP、認証、暗号プリミティブ、トランスポートの安全性を学んできました。

アルゴリズム、機械学習、検索

木、ヒープ、ハッシュ、文字列アルゴリズム、グラフ、動的計画法、ネットワークフロー、ヒューリスティック探索を扱います。計算量を分析し、処理内容に合ったデータ構造を選びます。

機械学習では、古典的なモデルとニューラルネットワークを実装し、勾配を導出・確認して、適切なデータ分割と指標で評価できます。確率モデル、分類、クラスタリング、CNN、再帰型ネットワーク、注意機構が背景にあります。

検索では、トークン化、転置索引、TF–IDF、BM25、PageRank を扱います。データ漏洩、誤差分析、再現性にも気を配ります。

グラフィックス、画像、信号

グラフィックスでは、幾何変換、カメラモデル、レイトレーシング、パストレーシング、空間加速構造を扱います。

画像と信号では、フィルタリング、再標本化、特徴抽出、畳み込み、フーリエ解析、FFT、FIR/IIR フィルタ、時間周波数解析を使います。

天文画像、音声実験、無線にこれらを応用します。エイリアシング、スペクトル漏れ、数値誤差、フィルタ応答も、最終的な画像や波形と同じくらい大切です。
