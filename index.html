我是 Pleniluner / 清月。

你也可以叫我 Pleniluner，或者 Elysia 都可以。

名字的来处

Pleniluner 取自 Plenilune Annals（盈月纪年），平时用在较正式的场合。我选择这个名字，是因为《盈月纪年》是有记载以来第一部在日本发售的中国东方同人作品。对于我来说这代表着中国的Touhou Fans 正在走向世界。 是的，一开始取盈月做银月，后面觉得清月更清爽，所以现在使用该名称。 （部分设备地区仍使用银月保持兼容性）

Elysia 取自 Elysia's Heart，是更亲昵的叫法。这首歌我喜欢了很多年。它听起来轻快、清爽又鲜明，我也希望自己能带着这种感觉，勇敢、独立地走好每一步。

我会用 C/C++ 做系统与性能相关的工作，用 Kotlin 写 Android 应用，也用 Python 和 MATLAB 处理计算、图像与信号。编译器、处理器设计、机器学习、硬件开发和计算机图形学，也都是我感兴趣的方向。

当然现在，跟我的Agent大人说去吧，我还以为是减速带呢，不好，孩子们，Transformer注意力不集中，上下文丢失，要开始玩验收矩阵了，Agent大人又在玩验收（YS）了。

我喜欢顺着程序一路追到指令，慢慢解开一道数学题，或从嘈杂的录音里找出一点能辨认的东西。

目前我的专业是建筑学、我的无线电台呼号为 BG7LBJ，同时我喜欢观星，感受星海的脉搏，当然调试和创作时，身边往往渲染着东方的音乐。

03 / 最近

手边正在做的事

Android 上的天象观测

正在用 Kotlin、Jetpack Compose 和 Android SDK 开发一款天象追踪应用。

我想让天文信息在界面上一眼就能看明白，也会琢磨动画、手势、缓存和性能，让应用用起来舒服一些。

无线电、信号与互联设备

正在探索 SDR、频谱分析、协议解码和数字通信，也在做一个结合无线电通信与深度学习的物联网项目。

无线电实验给了我一个实际场景，用来理解采样理论、滤波器、调制和噪声分析。

图像、音频与科学数据

正在使用开放天文数据集，探索图像校准、堆栈和后期处理。

音频方面，我关心数字滤波、编解码器、移动端音频处理和房间校正，也在探索用 WebRTC 实现实时音视频与数据通信。

算法与数学题

平时练习 ACM 风格的算法题，实现数据结构，研究图算法、动态规划和数论问题。

我也喜欢趣味数学和 AMC 题目，做题本身就有意思。

建筑与想象中的地方

正在围绕新中式建筑、中国水墨画与当代空间设计发展一些想法。

有些想法变成速写和模型，另一些则成了 Minecraft 里的建筑。

接下来想试试

还有几件想慢慢折腾的事：

  • 个人网站 — 给项目、笔记和创作找一个家，也留点地方试试新的视觉风格和交互。
  • 天正 + AI — 找找合适的 CAD MCP 工具，看看能不能与天正建筑 / TArch 配合。想让 AI 试着出图、改上几轮，再由我自己检查图纸。有些重复绘图的活，确实希望能有人搭把手。
  • 从课程作业走向小项目 — 借下面列出的课程资料，从作业和实验反过来想：要用好一门语言，我应该理解什么，又应该能独立做出什么？边学边把笔记和代码收在一起。
  • 银月工作站的黑苹果 — 为 ASUS ROG Strix G16（2025，G614PR）——银月工作站 / Pleniluner’s Workstation 折腾 macOS Sequoia 15，记录配置、兼容性和遇到的问题。后续的新版本 macOS，等确认硬件支持情况后再继续探索。

等这些事情逐渐成形，我会给它们建立各自的仓库，放代码、踩坑记录和后续更新。

计算机与程序

编程语言

C · C++ · Python · Java · Kotlin · JavaScript · MATLAB · SQL

界面和文档方面，还会用到 HTML、CSS 和 LaTeX。

汇编、硬件与并行计算

x86 / x86-64 汇编 · MIPS 汇编 · Verilog · VHDL · CUDA C++ · ISPC · POSIX 线程 · FPGA

系统方面的工作涉及内存管理、中断、进程、调度、同步和文件系统接口。我会借助汇编与调试工具，查看调用约定、栈帧、内存布局和可执行程序的行为。

数字硬件方面，我会处理组合与时序逻辑、处理器流水线、转发、停顿、异常和内存映射 I/O。

做并行程序时，我会观察线程同步、向量化、缓存行为、GPU 内存访问，以及限制加速比的各种开销。

编译器与软件构建

我会处理词法分析、语法分析、抽象语法树、符号表、类型检查、中间表示、控制流分析和寄存器分配。

编译器工具包括 Flex / JFlex 和 YACC / BYACC/J。

写 C++ 时，我会用到所有权、RAII、移动语义、模板和 STL。组织软件时，我在意清晰的接口、可管理的依赖、可复现的构建，以及能验证实际行为的测试。

应用、界面与网络

Android SDK · Jetpack Compose · Qt / Qt Widgets · Java Swing Django · SQLite · Scrapy · Lucene · WebRTC

我会构建包含持久状态、后台任务和网络通信的事件驱动应用。

这涉及 Android 生命周期、Qt 信号与槽、数据库访问和响应式界面。使用套接字时，也会考虑消息分帧、部分读取、超时和并发连接。

网络方面的知识包括 TCP/IP、路由、拥塞、DNS、HTTP、身份认证、密码学原语和传输安全。

算法、机器学习与搜索

我会使用树、堆、哈希、字符串算法、图、动态规划、网络流和启发式搜索，分析复杂度，再根据实际工作负载选择数据结构。

机器学习方面，我能实现经典模型和神经网络，推导并检查梯度，用合适的数据划分和指标评估结果。相关知识包括概率模型、分类、聚类、CNN、循环网络和注意力机制。

搜索方面，我会处理分词、倒排索引、TF–IDF、BM25 和 PageRank，也会留意数据泄漏、误差分析和可复现性。

图形、图像与信号

图形方面的工作包括几何变换、相机模型、光线追踪、路径追踪和空间加速结构。

图像与信号方面，我会用到滤波、重采样、特征提取、卷积、傅里叶分析、FFT、FIR/IIR 滤波器和时频分析。

这些方法会用在天文影像、音频实验和无线电里。混叠、频谱泄漏、数值误差和滤波器响应，和最终的图像或波形一样值得关心。
