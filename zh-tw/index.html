代碼、電波，還有一點幻想鄉。

我是 Pleniluner / 清月。

你也可以叫我 Pleniluner，或者 Elysia 都可以。

名字的來處

Pleniluner 取自 Plenilune Annals（盈月紀年），平時用在較正式的場合。我選擇這個名字，是因為《盈月紀年》是有記載以來第一部在日本發售的中國東方同人作品。對於我來說這代表著中國的Touhou Fans 正在走向世界。 是的，一開始取盈月做銀月，後面覺得清月更清爽，所以現在使用該名稱。 （部分設備地區仍使用銀月保持相容性）

Elysia 取自 Elysia's Heart，是更親暱的叫法。這首歌我喜歡了很多年。它聽起來輕快、清爽又鮮明，我也希望自己能帶著這種感覺，勇敢、獨立地走好每一步。

我會用 C/C++ 做系統與效能相關的工作，用 Kotlin 寫 Android 應用，也用 Python 和 MATLAB 處理計算、圖像與訊號。編譯器、處理器設計、機器學習、硬體開發和電腦圖學，也都是我感興趣的方向。

當然現在，跟我的Agent大人說去吧，我還以為是減速帶呢，不好，孩子們，Transformer注意力不集中，上下文丟失，要開始玩驗收矩陣了，Agent大人又在玩驗收（YS）了。

我喜歡順着程序一路追到指令，慢慢解開一道數學題，或從嘈雜的錄音裏找出一點能辨認的東西。

目前我的專業是建築學、我的無線電台呼號為 BG7LBJ，同時我喜歡觀星，感受星海的脈搏，當然除錯和創作時，身邊往往渲染著東方的音樂。

03 / 最近

手邊正在做的事

Android 上的天象觀測

正在用 Kotlin、Jetpack Compose 和 Android SDK 開發一款天象追蹤應用。

我想讓天文信息在界面上一眼就能看明白，也會琢磨動畫、手勢、緩存和性能，讓應用用起來舒服一些。

無線電、信號與互聯設備

正在探索 SDR、頻譜分析、協議解碼和數字通信，也在做一個結合無線電通信與深度學習的物聯網項目。

無線電實驗給了我一個實際場景，用來理解採樣理論、濾波器、調製和噪聲分析。

圖像、音頻與科學數據

正在使用開放天文數據集，探索圖像校準、堆棧和後期處理。

音頻方面，我關心數字濾波、編解碼器、移動端音頻處理和房間校正，也在探索用 WebRTC 實現實時音視頻與數據通信。

算法與數學題

平時練習 ACM 風格的算法題，實現數據結構，研究圖算法、動態規劃和數論問題。

我也喜歡趣味數學和 AMC 題目，做題本身就有意思。

建築與想象中的地方

正在圍繞新中式建築、中國水墨畫與當代空間設計發展一些想法。

有些想法變成速寫和模型，另一些則成了 Minecraft 裏的建築。

接下來想試試

還有幾件想慢慢折騰的事：

  • 個人網站 — 給項目、筆記和創作找一個家，也留點地方試試新的視覺風格和交互。
  • 天正 + AI — 找找合適的 CAD MCP 工具，看看能不能與天正建築 / TArch 配合。想讓 AI 試着出圖、改上幾輪，再由我自己檢查圖紙。有些重複繪圖的活，確實希望能有人搭把手。
  • 從課程作業走向小項目 — 借下面列出的課程資料，從作業和實驗反過來想：要用好一門語言，我應該理解什麼，又應該能獨立做出什麼？邊學邊把筆記和代碼收在一起。
  • 銀月工作站的黑蘋果 — 爲 ASUS ROG Strix G16（2025，G614PR）——銀月工作站 / Pleniluner’s Workstation 折騰 macOS Sequoia 15，記錄配置、兼容性和遇到的問題。後續的新版本 macOS，等確認硬件支持情況後再繼續探索。
  • 給 UV-K5 添一點幻想鄉 — 爲泉盛 Quansheng UV-K5 找找現成的東方 Project 主題，再嘗試安裝，或者適配到我正在使用的固件。
  • 電鍵與神光同步 — 探索把無線電電鍵接入 ASUS 官方 Aura Sync（神光同步），讓桌上的燈光跟着電鍵的節奏變化。

等這些事情逐漸成形，我會給它們建立各自的倉庫，放代碼、踩坑記錄和後續更新。

計算機與程序

編程語言

C · C++ · Python · Java · Kotlin · JavaScript · MATLAB · SQL

界面和文檔方面，還會用到 HTML、CSS 和 LaTeX。

彙編、硬件與並行計算

x86 / x86-64 彙編 · MIPS 彙編 · Verilog · VHDL · CUDA C++ · ISPC · POSIX 線程 · FPGA

系統方面的工作涉及內存管理、中斷、進程、調度、同步和文件系統接口。我會藉助彙編與調試工具，查看調用約定、棧幀、內存佈局和可執行程序的行爲。

數字硬件方面，我會處理組合與時序邏輯、處理器流水線、轉發、停頓、異常和內存映射 I/O。

做並行程序時，我會觀察線程同步、向量化、緩存行爲、GPU 內存訪問，以及限制加速比的各種開銷。

編譯器與軟件構建

我會處理詞法分析、語法分析、抽象語法樹、符號表、類型檢查、中間表示、控制流分析和寄存器分配。

編譯器工具包括 Flex / JFlex 和 YACC / BYACC/J。

寫 C++ 時，我會用到所有權、RAII、移動語義、模板和 STL。組織軟件時，我在意清晰的接口、可管理的依賴、可復現的構建，以及能驗證實際行爲的測試。

應用、界面與網絡

Android SDK · Jetpack Compose · Qt / Qt Widgets · Java Swing Django · SQLite · Scrapy · Lucene · WebRTC

我會構建包含持久狀態、後臺任務和網絡通信的事件驅動應用。

這涉及 Android 生命週期、Qt 信號與槽、數據庫訪問和響應式界面。使用套接字時，也會考慮消息分幀、部分讀取、超時和併發連接。

網絡方面的知識包括 TCP/IP、路由、擁塞、DNS、HTTP、身份認證、密碼學原語和傳輸安全。

算法、機器學習與搜索

我會使用樹、堆、哈希、字符串算法、圖、動態規劃、網絡流和啓發式搜索，分析複雜度，再根據實際工作負載選擇數據結構。

機器學習方面，我能實現經典模型和神經網絡，推導並檢查梯度，用合適的數據劃分和指標評估結果。相關知識包括概率模型、分類、聚類、CNN、循環網絡和注意力機制。

搜索方面，我會處理分詞、倒排索引、TF–IDF、BM25 和 PageRank，也會留意數據泄漏、誤差分析和可復現性。

圖形、圖像與信號

圖形方面的工作包括幾何變換、相機模型、光線追蹤、路徑追蹤和空間加速結構。

圖像與信號方面，我會用到濾波、重採樣、特徵提取、卷積、傅里葉分析、FFT、FIR/IIR 濾波器和時頻分析。

這些方法會用在天文影像、音頻實驗和無線電裏。混疊、頻譜泄漏、數值誤差和濾波器響應，和最終的圖像或波形一樣值得關心。

你問我什麼是車萬？

你說的對，但是《東方Project》是由上海愛麗絲幻樂團（ZUN）自主製作的一系列全新彈幕射擊遊戲。遊戲發生在一個被稱作「幻想鄉」的神秘世界，在這裡，人類、妖怪與神明共同生活，擁有不可思議力量的少女們透過「符卡規則」，以華麗的彈幕解決紛爭。你將扮演一位名為「博麗靈夢」的神秘巫女，或是一位名為「霧雨魔理沙」的普通魔法使，在自由的幻想鄉中邂逅性格各異、能力獨特的少女們，和她們一起展開激烈的彈幕對決，解決接連不斷的異變——同時，逐步發掘「幻想鄉」隱藏的真相。（bushi)
